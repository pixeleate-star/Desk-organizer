# Desk Organizer

This is a compact multi-purpose desk organizer designed to keep my everyday items organized in one place. It has different sections for different types of items like as u can see a large compartment for chargers and cables, a cylindrical holder for pens, pencils and markers, a small compartment for SD cards, USB drives and pendrives, and an open front area for my phone, keys and wallet.
The design is intentionally compact because my table has limited space. I wanted the organizer to be large enough to be useful but small enough to leave enough working space for my Mac.

## Why I Made This????

I made this because small desks can quickly become messy when chargers, stationery, USB drives, keys and other everyday items are left separately.
Instead of using multiple organizers, I designed one model that combines everything I regularly use. The dimensions were planned around my table so it uses minimal space while still providing enough storage.
The goal was to make something simple, practical and actually useful in my daily workspace rather than just making a decorative CAD model.
